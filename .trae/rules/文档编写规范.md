## 〇、目录宪法（目标态，🔴 强制）

### 0.1 一级目录 5 个（生命周期分类，v1.1 起）

| 一级目录 | 内容定位 | 归类判据（"读者第一动作"） |
|:--|:--|:--|
| `10-架构/` | 架构宪法、ADR（`adr/`）、跨模块实现逻辑总纲 | 问"系统整体怎么成立" |
| `20-需求/` | PRD / SRS / 需求规格 / 差距分析 / 完善计划 | 问"要做什么、验收什么" |
| `30-设计/` | 详细设计 / DDL / API 契约 / UI 与原型设计 | 问"长什么样、接口数据什么形状" |
| `40-实现/` | PMO 指令（`pmo/`）、在途特性（`features/`）、运维手册（`ops/`）、参考（`refs/`）、交付过程 | 问"怎么做、谁在做、做过什么" |

## 一、红线 R1~R13（违反 = Reviewer 判 FAIL）

| # | 红线 | 处置 |
|:--:|:--|:--|
| **R1** | 头部必带 `> 来源 / 日期 / 责任人` 3 行元信息 | 缺 → Reviewer 打回 |
| **R2** | 显式标注版本（v0.x 草稿 / v1.0 正式 / v2.0 修订） | 缺 → 不可进入评审 |
| **R3** | 文件名小写+短横线+日期 `YYYY-MM-DD`，数字前缀 2 位 | 违规 → 重命名 |
| **R4** | 文件类型白名单：`.md`/`.json`/`.mjs`/`.html`/`.sh`/`.txt`（限 2 个旧存留）| 其他后缀 → 移至 CDN 或仓库外 |
| **R5** | 禁图片（`.png`/`.jpg`）入 `docs/`（图片走外部 CDN，PDF 不入库） | 删除并通知起草人 |
| **R6** | 子目录深度 ≤ 3 层（不含文件本身） | 超 → 扁平化 + 通知 |
| **R7** | 文档内禁明文密钥/Token/密码，走引用 | 命中 → 立即恢复 git 历史 + 告警 P0 |
| **R8** | 删除文档需用户/PMO 批准 + commit hash 留痕 + 迁移映射表登记 | 违反 → 回滚 + 报告 |
| **R9** | 现行有效文档只加不删；过期归档/目录壳经批准 + HEAD 留底校验后可批量删除（v1.2，2026-09-28 实践基准） | 未批准删除 → 回滚 |
| **R10** | 引用其他文档用相对路径（`../{五类}/{子目录}/xxx.md`），禁绝对路径或 `<TODO>` 占位 | 占位符 → 打回 |
| **R11** | 新文档必须落入 §〇 生命周期五类目标态目录（禁止使用已删除的旧目录名建目录） | 拒收 |
| **R12** | 新建 PMO 命令/新模块时，**不再开一级目录**：模块名进文件名；PMO 指令落 `40-实现/pmo/`；任务表须写明落点五类目录 | 缺 → 拒收 |
| **R13** | 目录迁移必须批量执行 + 产出/追加**迁移映射表**（旧路径 ↔ 新路径全量对照）+ 同步 `docs/README.md` 与 rules/agents.md 引用；禁止零散迁移 | 零散迁移 → 回滚 |

| **13. 接口契约/契约** | `api-contract.md` | `30-设计/` |

| **15. 归档文档** | 不再建 `*-legacy/`；过期件按 R9 批准删除，映射表登记 | 溯源走 `docs/迁移映射-2026-09-28.md` + git 历史 |

### 2.1 元信息头（每份 .md 必带 ≥ 3 行）

```markdown
# <H1 标题>

> 来源: <PMO/Wave/姓名> | 日期: YYYY-MM-DD | 责任人: <角色>
> 版本: v1.0（v0.x 草稿 / v1.0 批准 / v2.0 修订）
> 追溯: PRD-{N} / PMO-{M}（可选）
```

### 2.2 Agent 工作流（写文档时自检 8 项）

- [ ] 归档位置按 §〇 五类归类判定（`10-架构` / `20-需求` / `30-设计` / `40-实现` / `50-测试`），未使用旧目录名
- [ ] 头部 3 行元信息完整
- [ ] 版本明确（v0.x → v1.0 必经评审）
- [ ] 文件扩展名在白名单（R4）
- [ ] 文件名小写+短横线+日期（R3）
- [ ] 引用文档用相对路径（R10），无 `<TODO>`/`<TBD>`
- [ ] 不涉及密钥/Token/密码（R7）
- [ ] 新模块不开新一级目录，模块名进文件名（R12）

### 2.3 文档与代码联动

| 触发事件 | 动作 |
|:--|:--|
| 模块新增/重命名 | **不开新一级目录**；模块名进文件名，落主意图对应五类目录（R12） |
| 废弃模块/目录 | 文件按主意图重迁入五类 + 迁移映射表登记；旧目录壳经批准删除（R9 v1.2） |
| PMO 执行完成 | 写 1 份交付报告入 `40-实现/`（过程）或 `50-测试/`（验收）+ commit hash 留痕 |
| 文档变更 | 同步 `.trae/rules/` 与根 `agents.md` 的路径引用；历史路径表述走 `docs/迁移映射-2026-09-28.md` 溯源 |

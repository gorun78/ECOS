## 一、红线 IR01~IR06（违反 = P0 事故，立即恢复 git 历史）

| # | 红线 | 处置 |
|:--:|:--|:--|
| **IR01** | 禁止在 gateway / 顶层 service 直接持有 PG 连接 / 改写 DDL——必须经 `engine-*-impl` 三层（Data/Service/Controller）访问 PG | P0 + Reviewer 静态检 |
| **IR02** | Flyway 永久禁用（`spring.flyway.enabled: false` 锁定于 7 处 application.yml），所有 schema 变更走手动 `psql -f` + `database/seed.sql` 同步 | R9 只加不删 |
| **IR03** | 禁止 DROP / ALTER / DROP COLUMN——只加表/加列/加索引，never 删/改已有 | R9 只加不删 |
| **IR04** | 禁止 `SELECT *`——MyBatis Mapper 必须显式列出查询字段 | 性能 + 安全 |
| **IR05** | 禁止裸 SQL 字符串拼接——多表/传参必须 PreparedStatement 或 MyBatis `#{}` 占位 | SQL 注入 = P0 |
| **IR06** | 禁止在 Engines / Runtime 自建 PG/Neo4j/MinIO/Doris/Git Driver——统一走 `runtime-access` | 架构铁律 §2.5 |

## 一、红线 DR01~DR08（命名 + DDL）

### 表名
| # | 规则 | 正例 | 反例 |
|:--:|:--|:--|:--|
| **DR01** | 表名小写 + 下划线 | `ecos_workflow_instance` | `Workflow_Instance` / `workflow-instance` |
| **DR02** | 新表前缀 `ecos_`（强制） | `ecos_workflow_instance` | `workflow_instance` |
| **DR03** | 表单数（业务对象或动作优先） | `ecos_workflow_task` | `ecos_workflow_task_v2` |
| **DR04** | JSONB 字段必加 `_json` 后缀 | `variables_json` | `variables` |
| **DR05** | 布尔字段 `is_` 前缀 | `is_active` / `is_deleted` | `active` / `deleted` |
| **DR06** | 审计 5 字段固定：`create_time` / `update_time` / `create_by` / `update_by` / `is_deleted` | — | `created_at` (V108 已 RENAME 入 V150) |
| **DR07** | 版本字段 `version_no VARCHAR(20) NOT NULL`（乐观锁） | — | — |
| **DR08** | 多租户预留：新表必带 `domain VARCHAR(50) NOT NULL DEFAULT 'default'` | — | — |

### 主键
| 风格 | 适用 | 示例 |
|:--|:--|:--|
| **UUIDv4 (推荐)** | 新表默认 | `id VARCHAR(36) PRIMARY KEY DEFAULT gen_random_uuid()` |
| **BIGSERIAL** | 纯内部 parent-child（性能优先） | `ecos_trace_sandbox_row.id BIGSERIAL PRIMARY KEY` |
| **复合** | 联合唯一 + 业务强相关 | `UNIQUE(domain, name)` |

### 索引
| 类型 | 命名 | 示例 |
|:--|:--|:--|
| 常规 | `idx_{表名}_{字段}` | `idx_wf_instance_status` |
| 部分索引 | `idx_{表名}_{partial}` | `idx_parasite_knowledge_type` |
| 唯一 | `uniq_{表名}_{字段}` | `uniq_source_id` |
| 过期索引 | **不删**，注释 `-- DEPRECATED` | — |

## 二、红线 EN01~EN03（执行 / 事务 / 数据流）

### 执行
| # | 规则 | 处置 |
|:--:|:--|:--|
| **EN01** | 所有 PG 访问必须走 HikariCP 连接池（spring 默认），禁止 `new DataSource()` | 静态检 |
| **EN02** | 事务边界 —— Service 层，单事务最多 1 个 commit 点 | DSL `@Transactional` 同方法 ≠ 跨表 |
| **EN03** | 批量 INSERT/UPDATE —— 必须 `REQUIRES_NEW` 子事务 + 单批 ≤ 100 | 防大事务 + PG MVCC 膨胀 |

### 数据流（跨引擎单向）
```
data-engine (D→I 抽取) ──主写──► 近源层 (ODS)
              │
              ▼
        ge-service (D→I 转化)
              │
              ▼ (读 ODS 只读)
   ontology-engine (业务对象 + 映射契约)
              │
              ▼
        知识工作台 (水K, 业务对象只读)
```
- 写 ODS 只属 `data-engine`（唯一事实源，铁律 §2.4 已证）
- `Ontology` / `Knowledge` 跨引擎读 ODS 只走 `runtime-access`，**不得绕 `BizObject` → 原生 SQL**
- 详细理由见 `架构铁律.md` §0.5 三工作台 5 条边界铁律

## 三、红线 ST01~ST06（三档 + 安全）

### 三档
| 档 | PG 行为 |
|:--|:--|
| standard | 默认 schema `public` |
| enterprise | `public` + `neo4j/排除` (`@Profile({enterprise, ultimate})`) |
| ultimate | `public` + `neo4j` + Doris 物化（单表 > 100 万行） |

| # | 规则 |
|:--:|:--|
| **ST01** | 表名中**禁止**含 `std_` / `ent_` / `ult_` 前缀（用 schema 隔离 + @Profile） |
| **ST02** | 跨档差量化（Neo4j/Doris 启用）必须 `@Profile({enterprise, ultimate})` 守卫 |

### 安全（继承架构铁律 §2.4）
| # | 规则 |
|:--:|:--|
| **ST03** | 敏感列（`name` / `phone` / `id_card` / `amount` / `password`）必加 `AES-256-GCM + KMS` 加密，读取解密，响应脱敏 |
| **ST04** | 列级过滤：敏感字段返回前必调 `POST /api/security/cls/columns` |
| **ST05** | 行级过滤：查询前必调 `POST /api/security/rls/apply` |
| **ST06** | 事件审计：写操作必发 Kafka `ecos.audit`（common-api `KafkaTopics.AUDIT` 常量） |

## 四、DDL 模板（新表）

```sql
CREATE TABLE IF NOT EXISTS ecos_{module}_{business} (
    id              VARCHAR(36) PRIMARY KEY DEFAULT gen_random_uuid(),
    -- 业务字段 --
    create_time     TIMESTAMP NOT NULL DEFAULT NOW(),
    update_time     TIMESTAMP NOT NULL DEFAULT NOW(),
    create_by       VARCHAR(100),
    update_by       VARCHAR(100),
    version_no      VARCHAR(20) NOT NULL,
    is_deleted      SMALLINT NOT NULL DEFAULT 0,
    domain          VARCHAR(50) NOT NULL DEFAULT 'default'
);
CREATE INDEX IF NOT EXISTS idx_{table}_{col} ON ecos_{module}_{business}({col});
```

### seed.sql 同步
- 新字典 → seed 必加（最小 3 行示例）
- seed 必须幂等（`ON CONFLICT DO NOTHING`）
- seed 与 V{n} 同 commit（同 PR 同 commit）

## 五、MyBatis Mapper 规范

### 三层（Data / Service / Controller）

| 层 | 职责 | 禁止 |
|:--|:--|:--|
| Data (DAO/Mapper) | 数据库 CRUD（XML） | 业务逻辑 / `if` 业务判断 |
| Service | 业务规则 / 事务 / 参数校验 | `JdbcTemplate` 直接连 |
| Controller | 入参校验 + 调 Service | `JdbcTemplate` 直接连（IR01） |

### XML 模板
```xml
<!-- INSERT -->
<insert id="insertX" parameterType="com.chinacreator.gzcm.xxx.dto.XxxDTO">
    INSERT INTO ecos_xxx (id, name, create_time, create_by, version_no, is_deleted, domain)
    VALUES (#{id}, #{name}, NOW(), #{createBy}, '1', 0, #{domain})
    <!-- 字段顺序必须与 DDL 严格一致 -->
</insert>

<!-- UPDATE 必带乐观锁 -->
<update id="updateX">
    UPDATE ecos_xxx
    SET name = #{name},
        update_time = NOW(),
        update_by = #{updateBy},
        version_no = version_no + 1
    WHERE id = #{id} AND version_no = #{versionNo} AND is_deleted = 0
</update>

<!-- DELETE 必为逻辑删除 -->
<update id="deleteX">
    UPDATE ecos_xxx
    SET is_deleted = 1, update_time = NOW(), update_by = #{updateBy}
    WHERE id = #{id} AND is_deleted = 0
</update>
```

### 禁止
- **禁** `SELECT *`（IR04）
- **禁** `${}` 传参 / `<if>` 多 SQL 拼接（IR05）
- **禁** 循环内查库 / 调远端（后端规范 §7）

## 六、JDBC 性能

| 项 | 设定 |
|:--|:--|
| 连接池 | HikariCP（spring 默认）|
| 最大连接 | 默认 30，按引擎差异化（data-engine 可 50） |
| 超时 | 默认 30s，写操作 ≤ 5s |
| 批量 | `REQUIRES_NEW` + 子事务单批 ≤ 100 |
| 全表扫 | 必加 `WHERE` + 命中 `idx_*`，PG `EXPLAIN ANALYZE` 闸门 |

## 八、迁移 / 变更流程

| 流程 | 命令 / 操作 |
|:--|:--|
| 新建 | `V{n}__{描述}.sql` 入 `gateway/src/main/resources/db/migration/`（n 单调递增） |
| 回滚 | 手写反向 `V{n}__rollback.sql`（Flyway 禁用，IR02） |
| 应用 | `psql -U postgres -d sys_man -f V{n}.sql && psql ... -f database/seed.sql` |
| 测试 | 标准三档 + enterprise + ultimate 三套 |
| 校验 | `psql -U postgres -d sys_man -c "\dt ecos_*"` 列对账 |
| 同步 | V{n} + seed.sql 同 commit（一个 PR） |

## PM 回复模板

### 待确认

```
✅ 测试计划完成：{task_id}

测试策略：
  单元测试：{n} 个用例（覆盖率目标 L2:60% / L3:75%）
  集成测试：{n} 个用例（覆盖 {m} 个 API）
  E2E 测试：{n} 个用例（L3 包含冒烟测试）

PRD 功能覆盖：
  总计：{n} 个 PRD 功能
  已覆盖：{m} 个
  覆盖率：{rate}%

阻断项：
  - F1.2 用户注册-验证码注册（无测试用例）

→ 请补充测试用例后重新提交确认
```

### 确认通过

```
✅ 测试计划确认通过：{task_id}

PRD 功能覆盖率：100% ✅
测试用例总数：{n} 个
  - 单元测试：{n} 个
  - 集成测试：{n} 个
  - E2E 测试：{n} 个（L3）

**deliverable_allowed: true** ✅
**可进入测试执行阶段**
```

### 确认拒绝

```
❌ 测试计划需补充：{task_id}

问题：
  - F1.2 用户注册-验证码注册 无测试用例
  - E2E-003 缺少边界条件测试

→ 请补充后重新提交确认
```

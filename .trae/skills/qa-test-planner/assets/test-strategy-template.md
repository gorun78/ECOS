## 测试策略模板

### 测试金字塔

```
        ┌─────────┐
        │   E2E   │   ← 少量，覆盖核心流程（PRD 关键路径）
        ├─────────┤
        │ 集成测试│   ← 中等，覆盖模块间交互（API 端到端）
        ├─────────┤
        │ 单元测试│   ← 大量，覆盖每个函数（Service/Controller）
        └─────────┘
```

### 测试环境

| 环境 | 用途 | 数据 |
|------|------|------|
| dev | 开发自测 | Mock 数据 |
| test | 集成测试 | 脱敏生产数据 |
| staging | E2E 测试 | 近似生产环境 |

### 覆盖率目标

| 层级 | L2 要求 | L3 要求 |
|------|--------|--------|
| 单元测试 | ≥ 60% | ≥ 75% |
| 集成测试 | 核心 API | 全量 API |
| E2E 测试 | 跳过 | 核心用户流程（PRD 关键路径） |
| **PRD 功能覆盖率** | **100%** | **100%** |

### 测试类型说明

| 类型 | 工具 | 特点 |
|------|------|------|
| 单元测试 | JUnit / Pytest | 快速、独立、可重复 |
| 集成测试 | REST Assured / Postman | 验证 API 端点 |
| E2E 测试 | Playwright / Cypress | 模拟真实用户操作 |

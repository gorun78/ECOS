| UT-002 | UserService.login | PRD-F2.1 | 用户登录-密码登录 | P0 | 已实现 |

### 追溯表生成规则

1. 每个测试用例必须有 `prd_ref` 字段，指向对应的 PRD 功能 ID
2. 一个测试用例可以追溯多个 PRD 功能（如 E2E-001 追溯 F1.1 和 F2.1）
3. 用例 ID 格式：`{类型}-{序号}`
   - UT: 单元测试 (Unit Test)
   - IT: 集成测试 (Integration Test)
   - E2E: 端到端测试 (End to End)

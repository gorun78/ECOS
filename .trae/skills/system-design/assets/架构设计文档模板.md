# 3. C3: 模块划分图

**关注者**：开发人员、架构师

## 3.1 模块列表

| 模块 | 英文名 | 职责 | 边界接口 | 归属层次 | 依赖模块 |
|------|--------|------|---------|---------|---------|
| 用户模块 | user-module | 用户管理、认证授权 | UserService | 应用层 | - |
| 订单模块 | order-module | 订单全生命周期 | OrderService | 应用层 | user-module, product-module |
| 商品模块 | product-module | 商品管理、库存 | ProductService | 应用层 | - |
| 支付模块 | payment-module | 支付处理 | PaymentService | 应用层 | order-module |

## 3.3 模块边界定义

### 用户模块边界

**职责范围**：
- 用户注册、登录、认证
- 会话管理
- 用户信息管理

**不负责**：
- 订单业务（由订单模块负责）
- 支付处理（由支付模块负责）

### 订单模块边界

**职责范围**：
- 订单创建、查询、取消
- 订单状态流转
- 订单支付发起

**不负责**：
- 支付结果处理（由支付模块回调）
- 商品库存扣减（由商品模块处理）

### 商品模块边界

**职责范围**：
- 商品信息管理
- 库存管理
- 商品搜索

**不负责**：
- 订单流程（由订单模块负责）
- 支付处理（由支付模块负责）

| 实体 | 英文名 | 说明 | 关联实体 |

# 5. C5: 流程与数据流图

**关注者**：开发人员、架构师

> **说明**：流程和数据流仅描述概要，不定义具体接口参数和返回值。

## 5.1 关键业务流程

### 业务流程列表

| 流程 ID | 流程名称 | 涉及模块 | 说明 |
|---------|---------|---------|------|
| BP-001 | 用户注册流程 | 用户模块 | 新用户注册并认证 |
| BP-002 | 下单支付流程 | 订单模块、商品模块、支付模块 | 用户下单并完成支付 |
| BP-003 | 订单履约流程 | 订单模块 | 订单状态流转和履约 |

### 业务流程: 下单支付流程 (概要)

**流程描述**：
1. 用户选择商品 → 提交订单
2. 订单模块校验库存（调用商品模块）
3. 库存充足 → 创建订单
4. 用户发起支付 → 跳转支付模块
5. 支付成功回调 → 更新订单状态
6. 订单完成

**流程图**：

```

  ▼
┌─────────────┐
│  提交订单   │
└──────┬──────┘
       │
       ▼
┌─────────────┐      校验库存       ┌─────────────┐
│  订单模块   │───────────────────►│  商品模块   │
└──────┬──────┘                     └─────────────┘
       │ 库存充足
       ▼
┌─────────────┐
│  创建订单   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  发起支付   │
└──────┬──────┘
       │

       ▼

   订单完成
```

**说明**：仅描述流程步骤和模块间交互，不定义接口参数和返回值。

## 5.2 模块间数据流向

### 数据流向列表

| 序号 | 数据流名称 | 源模块 | 目标模块 | 数据内容 | 流向类型 |
|------|-----------|--------|---------|---------|---------|
| DF-001 | 订单创建请求 | 前端 | 订单模块 | 订单信息 | 同步 |
| DF-002 | 库存查询请求 | 订单模块 | 商品模块 | SKU 列表 | 同步 |
| DF-003 | 库存查询结果 | 商品模块 | 订单模块 | 库存状态 | 同步 |
| DF-004 | 支付结果回调 | 支付系统 | 支付模块 | 支付状态 | 异步 |
| DF-005 | 订单状态变更事件 | 订单模块 | 通知模块 | 状态变更 | 异步 |

### 数据流向图

```
┌─────────────┐      DF-001       ┌─────────────┐
│   前端      │─────────────────►│  订单模块    │
└─────────────┘   (订单信息)      └──────┬──────┘
                                        │
                               DF-002    │
                    ┌──────────────────┼──────────────────┐
                    ▼                  │                  ▼
             ┌─────────────┐           │          ┌─────────────┐
             │  商品模块   │           │          │  支付模块   │
             └──────┬──────┘           │          └──────▲──────┘
                    │                  │                  │
                    │ DF-003           │                  │ DF-004
                    │ (库存状态)       │                  │ (支付结果)
                    └──────────────────┴──────────────────┘
                                        │
                               ┌────────▼────────┐
                               │   状态更新      │
                               └─────────────────┘
```

### 数据流说明

| 数据流 | 说明 | 同步/异步 |
|--------|------|----------|
| DF-001 | 前端提交订单信息给订单模块，包含商品列表和用户信息 | 同步 |
| DF-002 | 订单模块查询商品模块的库存状态 | 同步 |
| DF-003 | 商品模块返回库存状态给订单模块 | 同步 |
| DF-004 | 支付系统回调支付结果给支付模块 | 异步 |
| DF-005 | 订单状态变更后，发布事件通知通知模块 | 异步 |

**说明**：
- 数据流向描述模块间的数据交互，不定义具体的数据格式
- 数据格式由 api-design Skill 定义

# Prototype Recovery Skill

## Overview

A skill for front-end developers to recover/reimplement UI components from product prototypes with high fidelity. This skill addresses common failure points identified in actual prototype restoration projects.

## Getting Started

1. **Analyze Prototype**: Read the prototype HTML, CSS, and JS files
2. **Map Elements**: Create element mapping table
3. **Design Data Flow**: Define component contracts
4. **Implement**: Write code matching prototype exactly
5. **Verify**: Test complete user journey

## Key Features

- Complete prototype analysis methodology
- Data flow design before implementation
- Exact class name matching
- Comprehensive verification checklist
- Common failure pattern recognition and fixes

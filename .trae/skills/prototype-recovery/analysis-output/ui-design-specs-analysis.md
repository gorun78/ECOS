# UI设计稿设计规格分析报告

## 一、设计稿概述

设计稿采用 **Figma 导出** 的 React/TypeScript 格式，包含完整的页面布局和组件设计。

**设计稿位置**: `docs/01需求分析/01-政务窗口助手/01-UI设计/src/imports/`

## 二、配色方案分析

### 2.1 主色调对比

| 用途 | 设计稿颜色 | 前端实现 | 差异 |
|------|-----------|---------|------|
| 主色 | `#3370FF` | `#165DFF` | ❌ 偏深，需调整 |
| 主色渐变起始 | `#4E83FD` | `#4080FF` | ✅ 接近 |
| 主色渐变结束 | `#3370FF` | `#165DFF` | ❌ 偏深 |
| 背景色 | `#f6f8fd` | `#F2F3F5` | ❌ 偏白，需调整 |

### 2.2 辅助色

| 用途 | 设计稿颜色 | 前端实现 | 差异 |
|------|-----------|---------|------|
| 成功绿 | `#60D3BA` | `#00B42A` | ❌ 差异较大 |
| 警告橙 | `#F0873A` | `#FF7D00` | ✅ 接近 |
| 必填红 | `#d23a24` | `#F53F3F` | ✅ 接近 |
| 文字主色 | `#303133` | `#1D2129` | ✅ 接近 |
| 文字次要 | `#909399` | `#86909C` | ✅ 接近 |

### 2.3 配色结论

**设计稿实际使用的主色是 `#3370FF`**，比前端实现的 `#165DFF` 更亮更通透。

## 三、字体规格分析

## 七、修复建议

### 7.1 配色调整

```css
/* 主色调整：从 #165DFF 改为 #3370FF */
--primary: #3370FF;
--primary-light: #4E83FD;
--primary-dark: #3081FB;
--primary-bg: #f6f8fd;

/* 成功色调整：从 #00B42A 改为 #60D3BA */
--success: #60D3BA;

/* 警告色调整：从 #FF7D00 改为 #F0873A */
--warning: #F0873A;

/* 必填标记色 */
--required: #d23a24;
```

### 7.2 字体调整

```css
/* 添加 Roboto 字体 */
@import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;700&display=swap');

/* 字体族调整 */
font-family: 'Roboto', 'Noto Sans SC', sans-serif;

/* 字体大小调整 */
--font-size-lg: 20px;
--font-size-md: 16px;
--font-size-base: 14px;
--font-size-sm: 12px;

/* 行高调整 */
--line-height-lg: 40px;
--line-height-md: 20px;
--line-height-base: 18px;
--line-height-sm: 14px;
```

### 7.3 组件样式调整

```css
/* 按钮样式 */
.btn-primary {
  height: 44px;
  border-radius: 6px;
  background: linear-gradient(90deg, #4E83FD 0%, #3370FF 100%);
}

.btn-outline {
  height: 44px;
  border-radius: 6px;
  border: 1px solid rgba(51, 112, 255, 0.5);
  color: #3370FF;
}

/* 搜索框 */
.search-box {
  height: 58px;
  border-radius: 10px;
}

/* 卡片 */
.card {
  border-radius: 10px;
  box-shadow: 0px 0px 10px 0px rgba(51, 112, 255, 0.1);
}

/* 标签页 */
.tab-item {
  height: 38px;
  border-radius: 8px;
}

.tab-item.active {
  background: white;
  box-shadow: 0px 0px 10px 0px rgba(51, 112, 255, 0.1);
  color: #3370FF;
}
```

# 原型重构方案：从"技术能力并列"到"产品结构分层"

> 创建: 2026-10-13 | 状态: 待批准 | 依据: 用户反馈《我看了你上传的〈ECOS…〉》+ 现有原型 v1.0

## Context（为什么改）

现有原型 v1.0（1626 行单文件 HTML）把 ECOS 内部能力架构（认知域/智能域/W Agent/场景工作台）直接暴露为四个并列的产品入口，导致用户必须先理解"这些域分别是什么"才能开始解决经营问题。反馈文档明确指出：应重组为**以经营决策为主入口、认知资产中心/AI 工作台为专业域、平台管理为底座**的产品结构，并将 W Agent 从并列入口降为场景内的执行机制。

## 重构方案（新建 v2.0 文件，复用 v1.0 基础设施）

### 1. 导航重组

| v1.0（旧） | v2.0（新） | 变更说明 |
|:--|:--|:--|
| 场景工作台 | **经营决策** | 主入口，面向决策者，围绕"经营现状→需判断→待决策→行动效果"四问组织 |
| 认知域 | **认知资产** | 从"展示认知计算过程"转为"认知资产生产/维护/验证/发布/治理中心" |
| 智能域 | **AI 工作台** | 保留工具/模型/护栏/用量，吸收 W Agent 管理配置 |
| W Agent | ~~删除~~ | 降为场景内执行机制，页面合并入经营决策的任务阶段 |
| — | **平台管理** | 新增，数据源/本体/知识/权限/系统配置 |

**"问 ECOS"**：浮动全局入口（顶栏图标 + 悬浮输入框），非顶级菜单；场景内提问继承场景上下文。

### 3. 认知资产五类模型

原型中新增 `COG_ASSETS` 数据结构，覆盖五类资产及其关系：
- **Evidence**：来源/质量/适用范围/状态（已采集→已验证/有争议/已失效）
- **Hypothesis**：主张/验证方法/证据关联/状态（已提出→待验证→已证实/已证伪/暂不确定）
- **Belief**：判断/置信度语义/适用范围/版本（候选→当前采信/保留意见→被修订/被撤销）
- **Model**：注册/验证/发布/适用范围/回测（草稿→验证中→已批准→已弃用/已撤销）
- **CognitionResult**：运行引用/模型版本/口径版本/评估（运行中→成功/失败→已评估/已采纳/已被替代）

### 4. 场景首屏重构

从"场景完整度环 + 资源绑定 + 技术画布"转为四问面板：

```
┌─────────────────────────────────────────────┐
│  场景：2027 年度经营预测    [问 ECOS] ▾      │
├──────────────┬──────────────┬───────────────┤
│ 经营现状      │ 需要判断什么   │ 需要决定什么   │
│ 偏差目标列表  │ 未解决问题列表 │ 待比较方案     │
│ 指标变化      │ 运行中的任务   │ 待审批决策     │
├──────────────┴──────────────┴───────────────┤
│ 正在采取什么行动                           │
│ 进行中行动 + 进度 + 效果反馈               │

│ ▸ 配置与就绪（折叠区：完整度/数据质量/口径）  │
└─────────────────────────────────────────────┘
```

### 5. 技术策略

- **文件**：新建 `ECOS前端可交互原型-v2.0-2026-10-13.html`，v1.0 保留
- **复用**：CSS 四主题变量集、i18n 系统、事件委托（data-nav/data-act/data-act-chg）、toast/modal/drawer 基础件、SSE 帧引擎（完整复用）、W Agent 11 态状态机（完整复用，用于 AI 工作台运行监控页）、contractBar
- **演示态精简为四态**：normal / loading / error / forbidden（移除 empty/unavailable/stub/offline；stateGuard 四态化）
- **修改**：MODULE_HOME 映射表（4→4：decision/assets/aiwork/admin）、subnavFor 路由表、render() 分发逻辑、i18n 键
- **新增**：COG_ASSETS 五类资产数据结构、认知资产六页、场景首屏四问面板、平台管理页、"问 ECOS"浮动组件
- **删除**：W Agent 十一页串行（合并为场景内任务面板 + 决策/行动提升为一级页面）；认知域态势诊断/因果链从顶级 Tab 降为场景内分析视图入口
- **v1.0 基础设施搬迁**：v1.0 的 CSS 变量集/图标集/工具函数（esc/nav/toast/openModal/openDrawer/ic/parseRoute 等）直接复制到 v2.0；SSE_FLOWS/chatStart/chatNext/chatCut/chatResume 完整搬迁；runSim/runKill/runHistPush 完整搬迁

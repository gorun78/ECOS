## 五、门禁 V1 detail — JaCoCo 阻塞报告

### 5.1 现象

```
$ mvn install -P enterprise -DskipTests -Dmaven.test.skip=true -q
[ERROR] Failed to execute goal org.jacoco:jacoco-maven-plugin:0.8.12:check (check-bundle)
        on project data-engine-impl: Coverage checks have not been met.
[INFO] Rule violated: BUNDLE of project com.chinacreator.gzcm:data-engine-impl
[INFO]    covered ratio: 0/1.0 minimum 0.05
```

### 5.2 根因

`ecos_backend/pom.xml:618-640`（M0 改造 2026-09-01 添加）：

```xml
<!-- M0 改造 (2026-09): 加 <check> execution + 阈值 0.05 (起步, 不阻塞)
     后续按 08-产品化重构方案/05 §2.3 节奏递增:
     2026-09 0.05 → 2026-10 0.10 → 2026-11 0.20 → 2026-12 0.60 -->
<execution>
  <id>check-bundle</id>
  <phase>verify</phase>
  <goals><goal>check</goal></goals>
  <configuration>
    <rules><rule><element>BUNDLE</element>
      <limits><limit><counter>INSTRUCTION</counter>
        <value>COVEREDRATIO</value><minimum>0.05</minimum></limit>
      </limits>
    </rule></rules>
  </configuration>
</execution>
```

- 绑定 phase=verify（mvn install 跑 verify 阶段）
- `mvn install -DskipTests`：无测试 → 0 覆盖率 → 0 < 0.05 → build FAILURE
- `mvn install -P enterprise -DskipTests -Djacoco.skip=true -q`：✅ BUILD SUCCESS（已实测 2026-09-02 13:37）

### 5.3 验证证据

```
首次（带 jacoco.skip）：BUILD SUCCESS
  [controller] command_id=59dc7dd2-208b-4c81-bade-5307807cbfbf
  rc=0
二次（不带 jacoco.skip）：BUILD FAILURE（jacoco check-bundle）
  [controller] command_id=8df41de1-9712-4bbb-b94b-025ac8f27494
```

### 5.4 修复建议（另开 PMO-E4）

二选一：
- **(A) 关闭 check-bundle when -DskipTests**：`<skip>${maven.test.skip}</skip>` 在 jacoco check execution 内
- **(B) 起 verify profile 才启 check-bundle**：把 check-bundle 包到 `<profile><id>verify-coverage</id>`

两者都不动 pom 模块结构（不踩铁律"不加新 Maven 模块"）。

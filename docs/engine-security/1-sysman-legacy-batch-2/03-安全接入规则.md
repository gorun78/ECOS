# ECOS 安全接入规则

> 版本: Phase 1 | 生效: 2026-08-04 | 维护: ECOS-PMO

## 原则

1. 所有安全检查统一走 security-engine REST API
2. 各引擎不在自身代码中重复实现权限/脱敏/审计逻辑
3. 审计日志集中写 security-engine，各引擎不维护自己的审计表

## Phase 1 当前可用端点

| 端点 | 方法 | 用途 | 调用方 |
|------|------|------|--------|
| `/api/security/mask` | POST | 数据脱敏（SHA256/MD5/手机/邮箱/身份证/金额） | 所有引擎 |
| `/api/security/evaluate-filter` | POST | 安全过滤规则评估 | 所有引擎 |
| `/api/security/decrypt` | POST | 解密仿真（userId+orgId+datasetId） | 所有引擎 |
| `/api/security/audit-logs` | GET | 审计日志查询 | 所有引擎 |
| `/api/v1/auth/login` | POST | 用户登录（Gateway，security-engine提供验证） | 前端 |
| `/api/security/mask` | POST | 数据脱敏 | data-engine |

### mask 请求格式
```json
{
  "value": "13812345678",
  "maskType": "PHONE"
}
```
支持的 maskType: `SHA256`, `MD5`, `PHONE`, `EMAIL`, `ID_CARD`, `AMOUNT`

### mask 响应格式
```json
{
  "code": 0,
  "data": {
    "original": "13812345678",
    "masked": "138****5678",
    "maskType": "PHONE"
  }
}
```

### evaluate-filter 请求格式
```json
{
  "expression": "userRole == 'admin' OR orgId == rowData.orgId",
  "rowData": {"orgId": "org_001", "level": 3},
  "userRole": "viewer"
}
```

### evaluate-filter 响应格式
```json
{
  "code": 0,
  "data": {
    "result": true,
    "expression": "userRole == 'admin' OR orgId == rowData.orgId",
    "matched": true
  }
}
```

### audit-logs 响应格式
```json
{
  "code": 0,
  "data": [
    {
      "id": "audit_001",
      "timestamp": "2026-08-03T09:00:00",
      "userId": "admin",
      "action": "MASK",
      "resource": "phone_data",
      "result": "ALLOW"
    }
  ]
}
```

## 调用规范

- **请求超时**: 5秒（安全引擎应快速响应）
- **失败处理**: 安全引擎不可用时默认 DENY（宁可误拒不可误放）
- **审计日志**: 异步写入，不阻塞主流程
- **认证**: 所有 `/api/security/*` 端点需携带 JWT Bearer Token（除白名单路径外）

## 后续Phase接入指南

| 引擎 | 接入Phase | 接入时机 | 接入端点 |
|------|:--:|------|------|

| cognitive-engine | Phase 4 | 诊断/推理前调PBAC合规检查 | evaluate-filter |

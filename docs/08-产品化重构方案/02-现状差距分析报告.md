## 四、性能与稳定性（红线级差距）

### 4.1 性能现状（代码断层推断）

| 维度 | 现状 | 问题 | 影响 |
|:--|------|------|:--:|
| **前端 bundle** | 全量 import 55 个 pages（main.tsx:53）| 无 React.lazy / dynamic import | 首屏 100MB+ 加载 |
| **前端虚拟列表** | react-window 已购但未用 | 100+ 大表无虚拟滚动 | 滚动卡顿 |
| **前端组件拆分** | 35-40 个文件 > 800 行（最高 77K 行！）| AiGuardrailsView.tsx 77,208 行、ObjectExplorerView.tsx 63,097 行 | 编译卡顿、维护困难 |
| **后端 JdbcTemplate 直用** | **615 处**（100+ 文件）| 违反"Dao 封装 SQL 模板"规范 | N+1 查询风险 |
| **后端事务控制** | 仅 8 处 @Transactional（只在 data-engine）| sysman/engine/runtime/gateway 全 0 | 多表写无回滚 |
| **异常处理** | `throws Exception` 261 处（engine 40 文件 / sysman 42 文件）| 违反"抛 DataBridgeException 子类" | 堆栈泄露 |
| **Neo4j 直连** | 8 处 @Value 默认密码 | 部分未做超时 10s/1000 节点上限 | 连接泄漏 |
| **Cache** | 4 类缓存类（Permission/Decision/Dict/SysConfig）**无 Caffeine** | B1/B2 PMO 未落地 | 缓存雪崩风险 |

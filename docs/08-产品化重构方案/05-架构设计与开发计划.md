### 1.3 模块间接口契约

| 调用方向 | 协议 | 返回规范 | 备注 |
|------|:--:|------|------|
| 前端 → gateway | HTTP REST + SSE | ApiResponse&lt;T&gt; | 全端点在 `auth.whitelist.paths` 注册 |
| 引擎 → 引擎 | HTTP REST (跨端口) | ApiResponse&lt;T&gt; | 同进程调用建议 (sandbox 内调) |
| 服务层 → 引擎层 | HTTP REST | ApiResponse&lt;T&gt; | 实例化到 client (同进程优化) |
| 任意模块 → security | REST | {allowed: bool, reason?} | 默认 DENY, 不降级 |
| 任意模块 → runtime-task | REST | {taskId, status} | 禁自建 Scheduler |
| 任意模块 → llm-gateway | REST 流式 (SSE) | {delta, done} | 禁 Provider API 直调 |
| 引擎 → runtime-access | Bean (同 JVM) | — | 禁 new Driver |

### 1.4 关键契约变更（Phase 0 启动前必做）

| # | 契约 | 变更 |
|:--|------|------|
| 1 | Neo4j 访问 | **8 处 `@Value` 直读** → runtime-access/Neo4jConfig (P0 安全漏洞) |
| 2 | services/* 4 子模块 | Spring Boot 启动器 → library (Packaging=jar, 移除 spring-boot-maven-plugin) |
| 3 | JdbcTemplate 直用 457 处 | 分模块下推到 SqlRepository (Phase 1-2 完成) |
| 4 | 跨租户 RLS | security-engine 提供 `POST /api/security/rls/apply` → data-engine 查询前必调 |
| 5 | 列级过滤 | `POST /api/security/cls/columns` → 查询返回前必调 |
| 6 | 审计日志 | 所有写操作 → `POST /api/v1/security/audit/log` (异步不阻塞) |
| 7 | Agent 工具调用 | `POST /api/v1/security/policy-engine/evaluate` → OPA 裁决 |

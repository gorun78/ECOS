### RL-01 金额可追溯到输入快照

| 用例 ID | TC-RL-01-01 |
|---------|-------------|
| 测试要点 | 验证任意金额结果可追溯到输入快照 |
| 优先级 | P0 |
| 前置条件 | 预测运行 SUCCEEDED；结果明细存在 |
| 测试步骤 | 1. 随机抽取 10 条 `ecos_fc_result_detail` 明细行<br>2. 对每条明细调用 `GET /api/v1/workspace/forecast-runs/{runId}/evidence?detailId={id}`<br>3. 检查响应 `source_ref_json` 非空<br>4. 解析 `source_ref_json` 提取 `factRefs`<br>5. 查询 `ecos_forecast_input_snapshot` 验证 `fact_refs_json` 包含该 factRef |
| 预期结果 | 10/10 明细可追溯到快照；`source_ref_json` 与快照 `fact_refs_json` 一致 |
| 自动化 | 集成测试（JUnit） |

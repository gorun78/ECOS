## 四、现有表违规（不修，仅登记）

### 4.1 真非 `ecos_` 前缀（22 表，R9 不 RENAME，**未来新表必须用**）

**R9 例外列表**：
- `workflow` / `workflow_instance` / `workflow_task` / `workflow_approval` / `workflow_log` (V1.1)
- `workflow_task` (V108 重写为 `ecos_workflow_task` 同义)
- `sys_agent_session` / `sys_agent_message` (V101, BIGINT 不是 TIMESTAMP)
- `sys_dicts` / `sys_config` (V12/V13)
- `sys_compliance_rule` / `sys_extraction_source` / `sys_rule_version` (V100)
- `kd_*` / `kb_*` (kb-engine 引擎自带表前缀)
- `td_*` (td engine 自带表前缀)

### 4.2 `created_at` → 必在 V150 后 RENAME

V150 实施后，所有 26 张含 `created_at` 的表都会 通过兼容视图 `v_*` 自动支持 `created_at` 查询。新写代码直接用 `create_time`。

### 4.3 无 `_json` 后缀的 JSONB（13 处，仅 legacy）

历史 13 处 JSONB 字段无 `_json` 后缀（如 `variables JSONB`、`context JSONB`）。新表必带。

### 4.4 无 `domain` 列 96 张 + `version_no` 96 张

存量表不补（R9 不自修）。V150+ 新表必带 + DR06/DR08 红线。

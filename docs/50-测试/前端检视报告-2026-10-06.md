## 四、诚实登记 · 上一轮 P3-A 结论勘误

上轮 v2 报告 `【校订 2026-10-06 · P0-4 独立批次收口】` 段内标记 P3-A 为「React key 告警（本轮复现 · DataAssetsDashboard 传入 select 的子项缺 key）」。**本轮 grep 复核修正**：`DataAssetsDashboard.tsx` 内**所有** map 生成的 `<option>` 均带 `key` prop（L139/148/406/417/428 各处）；**真源是 L133/L146 两个静态 `<option value="">`（"全部层级"/"全部类别"）与 map 结果混排在同一 `<select>` 里** —— React list-reconcile 检查首个子节点缺 key 时报"Each child in a list should have a unique key · passed a child from DataAssetsDashboard"，trigger 组件名被 React 归到**外层 render 函数名的最近 select**，故 console 指向 DataAssetsDashboard 而非具体行。

修复 = L133/L146 各加 `key="__all"` 或改由 map 内插 `<option value="">` 一条（去掉静态行）。仍属 P2 中的 P3 老 P3 层（不影响用户 200 / 不影响数据），非红线。

## 二、判定与证据（速查，详版见主方案）

| 判定 | 含义 | 计入通过率 |
|---|---|---|
| PASS | 有 L2+ 证据且断言命中 | 是 |
| FAIL | 断言未命中 | 否 |
| PARTIAL | 有未执行分支 | 否 |
| BLOCKED | 前置不满足 | 否 |
| NOT_EXECUTED | 未跑 | 否 |
| N/A | 不适用 | 否 |

**证据等级**：L1 单测 / L2 活体 API / L3 活体 UI / L4 直查 PG 对账。写操作 PASS 至少需 L2+L4；界面 PASS 至少需 L3。每个 PASS 必填「命令 + 原始输出 + 断言值」三元组。

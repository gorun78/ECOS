## 一、判定口径

| 类别 | 判通过的条件 |
|---|---|
| render | `<main>` 有可见正文、不落 ErrorBoundary；无未声明 4xx/5xx；无未声明 console error |
| redirect | 旧路径必须收敛到新正典 hash |
| param（带假 ID） | 页面渲染出正文并**如实呈现"对象不存在"**（不崩、不白屏）；"不存在"类错误属预期 |
| fallback（`*` 404） | 未知 hash 必须落兜底页并显示 404 标识 |

**三条反假绿机制**（缺一不可）：

1. **逐条判定**：任何一条超时也产出 FAIL 结论（`页面 20s 内无正文`），不允许因一条卡死把后续判成「未判定」。
2. **二次探针**：首屏报出的每个 4xx/5xx 都**同路径重放一次**。首屏失败但重放 200 ⇒ 标为 FLAKY（瞬时抖动），既不当通过也不计入后端缺口。
3. **失败分层**：失败项必须落到「后端缺口（带 D 编号）」或「未归因」两类之一；**未归因必须为 0** 才允许判定本批收口。

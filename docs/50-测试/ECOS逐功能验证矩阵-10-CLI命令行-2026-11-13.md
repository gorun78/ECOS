## 一、CLI 定位与验收锚点

### 1.1 它是什么

ECOS 控制面命令行：**只经 gateway :8080**，每条命令持 operationId 而非 URL 字面量，写操作分级（L0 只读 / L1~L2 直接写 / L3 需 `--approval-token` 且服务端复核）。

## 十、判定补充说明（CLI 特有）

1. **「命令能跑」不等于「功能达成」**：必须核 `operationId` 对应的后端行为，CLI 只是壳
2. **「退出码 0」不等于「业务成功」**：CLI status 五值与退出码分离，须同时核
3. **「未接命令」不算 FAIL，但必须显式**：静默成功才是 FAIL
4. **L3 恒 403 不算 PASS**：这是授权墙缺陷，「拒绝」是正确行为但「该成功时成功」未达成

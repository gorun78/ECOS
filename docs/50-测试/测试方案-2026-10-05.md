6. **证据优先**：断言只认 DB 行数 / HTTP 状态 / DOM / 快照 checksum；「人工确认」类验收禁单测化。
7. **DEMO 口径**（PRD-09 R-63 ②）：预测场景前置表实测全 0 → seed 必须显式 demo 源 + 界面 DEMO 徽标，否则金标准对账不成立。

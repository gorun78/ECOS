## 一、清理原则（红线）

1. **Doc-First**：每个删除前必须先确认文档中没有引用（grep `*.md`）
2. **Git-Backed**：所有删除走 commit，commit message 标注 `chore(cleanup): 删除 xxx 冗余文件`
3. **Ticket-Tracked**：每个清理动作对应一个 PMO Task，含验收命令
4. **不破坏编译**：每次删完必跑 `mvn install -DskipTests` + `tsc --noEmit` 验证
5. **可回滚**：单次清理不超过 30 文件 (Step 1 不超过 50), 单次 git commit 可 `reset`

#### 3.3.2 文档版本控制

| 原则 | 规则 |
|------|------|

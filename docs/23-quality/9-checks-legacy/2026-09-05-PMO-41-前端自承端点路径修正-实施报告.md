## 2. 修改明细（4 文件，+51 / −17）

### T1 — `ecos_frontend/src/services/ontologyApi.ts`

### T2 — `ecos_frontend/src/services/agentConfig.ts`
- `fetchKnowledgeBases` 路径 `/v1/knowledge-bases` → **`/knowledge-bases`**（`apiFetch` 前缀 `API_BASE="/api"` 自动补全 → `GET /api/v1/knowledge-bases`）。

  相对指令可能已陈旧；仅路径 + JSDoc 校正。保留 `Promise<KnowledgeBase[]>` 签名。

### T3 — `ecos_frontend/src/pages/sql-query-console/api.ts`
- 拆分为 `TEMPLATE_LIST_URL = '/api/v1/engine/data/query/templates'`（复数，列表/删除）
  + `TEMPLATE_SAVE_URL = '/api/v1/engine/data/query/template'`（单数，保存）。
- 后端 `QueryController` 实际：`GET /templates`、`GET /templates/{id}`、`DELETE /templates/{id}`（复数）、
  `POST /template`（单数）— 故 `saveTemplate` 保持单数（避免方向性 bug），`fetchTemplates`/`deleteTemplate` 改复数。
- 函数签名不变；JSDoc 标注复/单数依据。

### T4 — `ecos_frontend/src/pages/aiworkbench/api.ts`
- `fetchAgentMetrics` / `fetchAgentErrors` 路径 `/api/v1/agent-metrics/...` →
  **`/api/v1/aip/agent-metrics/...`**（后端 `AgentMetricsController @RequestMapping("/api/v1/aip/agent-metrics")` 主路径）。
- 字段对齐后端实际返回：`totalCount`→`totalCalls`、`avgElapsedMs`→`avgLatencyMs`、`p99Ms`→`p99LatencyMs`（用 `??` 兜底，字段兼容）。

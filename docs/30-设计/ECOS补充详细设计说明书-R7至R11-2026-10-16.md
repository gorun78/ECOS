> 本节为原册 §2.9.4（[L1032-L1079](file:///d:/workspace/javaprojects/ECOS/docs/30-%E8%AE%BE%E8%AE%A1/ECOS%E8%AF%A6%E7%BB%86%E8%AE%BE%E8%AE%A1%E8%AF%B4%E6%98%8E%E4%B9%A6-%E4%BB%8E%E9%9B%B6%E5%AE%9E%E6%96%BD%E7%89%88-2026-10-12.md#L1032-L1079)）的 R7 增量补充。原册内容不变，本节仅补裁决落位。

**④ 审计四级映射（裁决落位）**：

> **裁定（2026-10-16 · PMO · 同步 Q-1/DQ-1）**：**维持 L1~L4 四级**（L1 常规 / L2 受控 / L3 高风险 / L4 关键）。用户指出四级可作为基线但**允许简化为三级**（记为**降级选项，非默认**），以避免治理过度复杂；仍须与既有 `clearance_level`（L0 公开~L4 绝密）/ `audit_mode` 核对映射后生效，**严禁替换现有安全等级定义**。

| 等级 | 典型对象 | 版本与审批 | 运行态发布 |
|:--|:--|:--|:--|
| L1 常规 | 非敏感描述、展示配置、低风险标签 | Git 版本 + 自动校验 + 常规留痕 | 授权范围内可自动发布 |

## §2.9.6 发布 / 双写状态机、失败恢复与对账（补充）

> 本节为原册 §2.9.6（[L1125-L1148](file:///d:/workspace/javaprojects/ECOS/docs/30-%E8%AE%BE%E8%AE%A1/ECOS%E8%AF%A6%E7%BB%86%E8%AE%BE%E8%AE%A1%E8%AF%B4%E6%98%8E%E4%B9%A6-%E4%BB%8E%E9%9B%B6%E5%AE%9E%E6%96%BD%E7%89%88-2026-10-12.md#L1125-L1148)）的 R7 增量补充。

**① 发布状态机（16 态）**：

```
主链: DRAFT → VALIDATING → PENDING_APPROVAL → APPROVED → READY_TO_APPLY
      → APPLYING → APPLIED → VERIFYING → SUCCEEDED
旁支: REJECTED / PARTIAL_FAILURE / FAILED / ROLLBACK_PENDING / ROLLING_BACK
      / ROLLED_BACK / DRIFTED
```

**红线**：Git 与 DB 属不同持久化系统，**不构成天然单一原子事务**；`Git 提交成功 ≠ DB 应用成功 ≠ 安全审计通过`，三者分别记录；**禁把部分成功报完全成功**。

**② 失败恢复**：Git 写入失败/审批过期/依赖冲突→保留上下文待重试或人工；DB 部分成功→标 `PARTIAL_FAILURE` + 幂等应用 + 补偿/重试；领域 API 超时→持久化发布任务（runtime-task 真实 `taskId`）+ 安全重试 + 对账；回滚→**优先发布已知历史版本（git ref 检出重应用），非任意反向 SQL**；不可逆变更→专门恢复流程；审计不可用→**关键安全变更 fail-closed**。
**③ 对账 8 类判定**：一致 / 缺失对象 / 多余对象 / 内容漂移 / 版本引用不匹配 / 部分发布 / 依赖不一致 / 无法验证。自动修复不得绕过审批。

> **(a) Redis 连接与容器：不接（维持挂账）**。铁律「不新增 Docker container」在本裁决前仍然有效；当前进程内 TTL 已满足「受控加速层」语义，接 Redis 的唯一增量是跨节点共享，属**部署规模问题**而非设计缺口。解除条件写成三条硬前置：① 有跨节点一致性的实测需求（非推测）；② runtime 底座补远程实现且 `redis_enabled=true` 时**必须显式降级**（现开关已存在、缺载体）；③ 单独裁决容器与凭据注入。

> **(c) Outbox / 事务消息：不做通用框架，做单点最小实现（按需）**。现状「先提交权威数据、再失效缓存」已由写路径显式调用（#147AA 的 `evictUser`/`evictAll`）；通用 Outbox 要新建表 + 轮询器 + 幂等消费，收益仅在「跨节点失效广播」——与 (a) 绑定，故一并挂账。若先做，最小形态 = 写路径同事务落 `cache_invalidation_outbox` + `runtime-task` 轮询发布（复用 `runtime-event`，不接新中间件）。

## 〇、一句话结论

ECOS 数据层的「乱」不在单点，而在**四处结构性分叉**：

1. **DDL 有 3 套竞争性单源目录 + 1 处引擎散落**：`gateway`（197，V1~V244）/ `sysman-boot`（16，V 号与 gateway **前 14 个文件名完全同名但内容不同**）/ `sysman-boot/database`（3，V1.4-V1.5）/ `ai-engine`（1 散 V4）。
2. **两套「真源」并存**：gateway 增量 `V*` 与 `ecos-sql/postgresql/01~08` 全量快照，**仅 21 张表严格双源**（另 49 bare-name 双源）——即任一「单源」都不覆盖现网。
3. **现网 686 个对象里只有 123 落在 ST07 五引擎 schema**；220 塞在 `public`（215 主控制 + 5 演示 stray，未切 `ecos_control`）、208 塞在 `ecos_demo`（含 39 张 Flowable `act_*` 演示态）、133 在 knownLegacy。
4. **数据访问 runtime 收口其实已干净**（0 处自建 `DataSource/MinioClient/DriverManager/KafkaTemplate` 在 runtime 之外），真正违规是 **13 处 ST09 跨引擎写对方 schema 表**（最高 = `DataSourceServiceImpl` 自建 `MinioClient`）。

本方案给出**可逆的彻底初始化**：先冻结现网基线（已做，[full-schema-only.sql](./canonical-baseline/captured-live-2026-10-05/full-schema-only.sql) 679 表 / 3.9 万行）→ 定义**单一 canonical DDL 基线目录 + 单一（按业务族的）文件序** → 生成**可复现重置脚本**（rehome `public`→`ecos_control` · drop `ecos_demo` · 重放 canonical DDL + seed）→ 改写**数据库访问与脚本存放规则**（新增 ST10 单源升级 + DA01~DA05 访问规约）→ 产出 **13 处数据访问违规的修复指令台账**（交代码 owner，非本批执行）。

**红线**：`ecos_demo`（208）为演示数据、非业务契约，是本次「彻底初始化可删」的主要对象；`public`/五引擎 schema 属核心承载，**只重排不丢**（先 rehome 到 `ecos_control` 再重建，knownLegacy 只停写不物理迁移）。**任何 drop 前，`canonical-baseline/` 快照 + TSV 双重可回滚**。

**关键设计决策**：
1. **单 V 命名空间废弃** → 改为「**按 schema / 业务族切文件**」（`00-init / 10-control-main / 20-engine-xxx / 30-business-dw / 40-legacy-frozen / 99-seed`），**彻底消除 V 号同名冲突**。原 `V{n}` 语义保留为文件头注释「变更历史戳」（`-- origin: V150__x + V200__y (merged 2026-10-05)`），不再作执行序。
2. **执行序 = 目录号前缀 + 文件名字母序**：`00-init → 10-control-main → 20-engine-*（按字母 data<ontology<kb<ai<cognitive）→ 30-business-dw → 40-legacy-frozen → 99-seed`；无 Flyway，纯 `psql -f` 依目录顺序（IR02）。
3. **`ecos-sql/{postgresql,mysql,oracle}/01~08` 退役** → 内容并入 `99-reference-snapshots/8split-knownLegacy/`，**标 knownLegacy 保留可读**（R9 只增不删），不再作真源；mysql/oracle 保留作多库兼容对照样本（MC 系列），标注「示意态，现网不跑」。
4. **4 处单源违规收编**：`ai-engine/V4` · `ontology/ecos_action_type` · `sysman-boot/db/migration/*(16)` · `sysman-boot/database/*(3)` 全部**内容并入 canonical 对应族**；原目录**留 `RETIRE.txt` 空 stub 指向 canonical**（不物理删，最小扰动并行窗口）。
5. **`12_to_8_schema.sql` + `V150__schema_unify.sql`** → `40-legacy-frozen/onetime/`（一次性历史脚本，无重放需求，保留作证据；未来重放以 canonical 为准）。

## 附 §教训 — 本 goal 内踩过的坑（升格规约）

1. **Mockito-inline on Windows surefire**：MVN_OPTS 的 `-Djdk.attach.allowAttachSelf=true`
   不会传给 surefire fork JVM。需要额外挂到 surefire `argLine`：
   `mvn ... -DargLine="-Djdk.attach.allowAttachSelf=true"`。
   否则 `AlertPersistenceTest` / 同类 `mock(JdbcTemplate.class)` 会 false-positive 挂。
2. **`config / baseline` 白名单类测试**（e.g. `ConfigSingleSourceArchTest`）：删字段必须同步删
   方法/注释，否则 annotation 仍引用常就会缺符号编译错。本文所在 commit 938f46a9 是
   mid-edit 恢复兜底。
3. **B0 gate 原文 pattern** 不含 `ecos_dq`（只有 `public.ecos_ / ecos_identity / ecos_agent /
   ecos_audit`）——生产代码现行零残留按 B0 原文即可。
4. **001__ 硬编 schema 前缀摸不到**：用户之前曾把 `ecos_dq.dq_*`（旧 schema）当作 R1 阻断
   项，但指令 B0 gate 原文明确不含 `ecos_dq`（V200 是 8 schema 封闭枚举重构，
   `ecos_dq.*` 属 V166 冻结迁移脚本里的老模型，已由 `public.ecos_dq_*` 迁到 V166 定版
   DDL —— 测试刻意断言 "冻结脚本不迁移"）。本回合不再对 `ecos_dq.*` Javadoc
   做硬修。

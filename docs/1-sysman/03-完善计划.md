## 二、T1: 登录安全增强（2天）

### T1a: 登录失败锁定（1天）

**改文件**: `sysman-boot/.../controller/AuthController.java`

**DB变更**: `users`表加字段
```sql
ALTER TABLE users ADD COLUMN failed_attempts INT DEFAULT 0;
ALTER TABLE users ADD COLUMN locked_until TIMESTAMP NULL;
ALTER TABLE users ADD COLUMN password_change_required BOOLEAN DEFAULT TRUE;
ALTER TABLE users ADD COLUMN last_password_change TIMESTAMP DEFAULT NOW();
ALTER TABLE users ADD COLUMN password_history TEXT DEFAULT '[]';  -- JSON数组，存最近N次密码hash
```

**AuthController.login改造**:
```java
// login方法中，密码验证前加锁定检查:
// 1. 查 failed_attempts, locked_until
// 2. 如果 locked_until > NOW() → 返回 "ACCOUNT_LOCKED" errorCode
// 3. 密码错误:
//    failed_attempts++
//    如果 failed_attempts >= maxAttempts（从SysConfig读）→ locked_until = NOW() + lockoutMinutes分钟
// 4. 密码正确:
//    failed_attempts = 0, locked_until = NULL
//    如果 password_change_required = TRUE → 返回 "PASSWORD_CHANGE_REQUIRED" errorCode（带临时token）
//    如果密码过期（last_password_change + expire_days < NOW()）→ 返回 "PASSWORD_EXPIRED" errorCode
```

**错误码定义**（新增到common-api的ErrorCode枚举）:
```java
ACCOUNT_LOCKED(423, "账户已锁定，请{minutes}分钟后重试"),
PASSWORD_CHANGE_REQUIRED(428, "首次登录需修改密码"),
PASSWORD_EXPIRED(429, "密码已过期，请修改密码"),
PASSWORD_WEAK(422, "密码强度不足：需至少{minLength}位，包含{requirements}"),
```

### T1b: 密码强度校验（0.5天）

**改文件**: `sysman-boot/.../controller/AuthController.java`（新增changePassword方法）

```java
@PostMapping("/change-password")
public ApiResponse<Map<String, Object>> changePassword(@RequestBody ChangePasswordRequest req) {
    // 1. 验证临时token（从login返回的PASSWORD_CHANGE_REQUIRED中携带）
    // 2. 校验密码强度：从SysConfig读 password_min_length/require_upper/require_digit/require_special
    // 3. 校验与历史密码不重复：读password_history JSON数组
    // 4. BCrypt加密新密码 → 更新password_hash
    // 5. password_change_required = FALSE, failed_attempts = 0
    // 6. 新hash推入password_history（只保留最近N条，N=SysConfig的password_history_count）
}
```

### DataInitializer.seedRoles()
```java
private void seedRoles() {
    long count = jdbc.queryForObject("SELECT COUNT(*) FROM roles", Long.class);
    if (count > 0) { log.info("Roles exist, skip seeding"); return; }
    
    for (RoleDef role : loadRoleDefs()) {
        jdbc.update("INSERT INTO roles (name, display_name, description) VALUES (?,?,?)",
            role.name, role.displayName, role.description);
        for (String perm : role.permissions) {
            jdbc.update("INSERT INTO permissions (role_name, resource, action) VALUES (?,?,?)",
                role.name, perm.split(":")[0], perm.split(":")[1]);
        }
    }
}
```

## 一、红线与当前结论

DS-4 的 DROP 例外（架构铁律 §3.1）前置是：**备份 + 代码读写先切 Git 链路**。当前三表仍被生产代码 INSERT：

| 表 | live 行数 | 写路径 | 读路径 |
|---|---|---|---|
| `ecos_ontology.ecos_ontology_version` | **2** | `OntologyVersionDao.insert`（publish/rollback 三处） | `OntologyVersionDao.find*`、`OntologyGitHistoryApiController` |
| `ecos_control.ecos_object_version` | **0** | `common-api ObjectRuntimeDao`（对象运行时版本） | 同 DAO |
| `ecos_control.sys_rule_version` | **0** | kb `ComplianceRuleDao.insertVersion` | `ComplianceRuleVersionService.getVersions`（已优先按 `git_ref` 读回） |

**本轮已执行（授权内、非破坏）**：三表 `pg_dump` 备份（`/tmp/ds4-version-tables-bak-20261108-123453.sql`，44,651 B）＋读写面盘点。

**本轮未执行**：停写、读面切 Git、DROP。原因：三域读面尚未具备 Git 历史枚举能力（见下），此时停写会让版本历史与规则版本查询直接空掉——属功能破坏，不是迁移。

## 三、逐域迁移步骤与验收门

### 3.1 本体版本（`ecos_ontology_version`，2 行，最先做）

**第一批（2026-11-08 已完成，活体验证）**：
- 新增 `OntologyGitHistoryReader`（`ontology-engine-impl`）：以 `Publish ontology <id> <version>` 提交为版本事件，
  按 `ontologies/<id>/<version>.json` 读回内容；id 方案 `git-<commitId>`。
- 历史/列表/详情读面切换：`gitHistoryVO`、`listVersions(VO)`、`getVersion(VO)(ById)` 已优先 Git；
  库内只补「未归档」行（草稿/在工作态）。`contentSource=GIT`。
- **活体证据**：`GET :8080/api/v1/ontology/git/history?ontologyId=ont_entmgmt` → 2 行
  （`git-fcfdee94…` 1.0.1 / `git-9b03ceec…` 1.0.0，status Published）；
  详情读回 snapshot 的 sha256 = Git 文件 sha256 = `c1b0fc62224c…767d`（逐字一致）。
- 单测：`OntologyGitHistoryReaderTest` 5/5（过滤、缺文件 fail-loud、仓库未注册 fail-loud）；本体模块全量 **313/0**。

**第二批（2026-11-08 已完成，活体验证）**：
- 草稿/状态事件化：`Draft ontology …` → `ontologies/<id>/drafts/<ver>.json`；`Deprecate ontology …` →
  `ontologies/<id>/status/<ver>.json`；发布仍为 `Publish ontology …` → `ontologies/<id>/<ver>.json`。
- `createVersion/publishVersion/deprecate/rollback` 在 Git 可用时全部走事件提交，**零 DB 写**；
  发布态三腿记录 DB 腿显式为 `NOT_APPLICABLE`（不再被误判 `PARTIAL_FAILURE`）。
- **活体验证**：创建 1.0.2 → Draft（`git-cfa2c7fb…`）；发布 → Published
  （`git-39fd8d66…`，`publishState=VERIFYING`，`git=SUCCEEDED, db=NOT_APPLICABLE, audit=SUCCEEDED`）；
  弃用 → Deprecated；全程 `ecos_ontology_version` 行数 **恒为 2**（零写）。
- 单测：本体全量 **313/0**（含 reader 5/5）；Git 日志 5 条事件（Draft/Publish/Deprecate 全在位）。

**第三批（2026-11-08 已完成，DROP 后活体验证）**：
- `diff/diffVO/diffWithPrevious(VO)` 与 `publishVersionById` 全部支持 `git-<sha>`；列表/历史在 Git 可用时**不再触库**。
- `V323__drop_ontology_version_history_table.sql` 已执行：`ecos_ontology.ecos_ontology_version` **已 DROP**（备份
  `/tmp/ont-version-bak-20261108-153603.sql`，41,296 B；此前全表备份 44,651 B 亦在）。
- **DROP 后活体**：列表/历史 200（1.0.2 Deprecated + 1.0.1/1.0.0 Published）；两版本 diff 200；
  新建 1.0.3 Draft → 发布 **Published（publishState=VERIFYING）**，全程无表可写、无 500。
- 门禁：本体全量 **313/0**；DDL/版本/口径门 **35/0**（Migration/DDL 对齐/DrBaseline/Mc02/Mc03/OntologyNoFactValue）。

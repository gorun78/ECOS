## 四、跨环境（WSL ↔ Windows）共存

**当前同一台机器 Docker Desktop 共用 infra：**
- PostgreSQL 5432 / Neo4j 7687 / MinIO 9000 / OPA 8181 / Kafka 9092 全部 UP

**原则：**  
两端的 java/node 进程**共用同一组 DB**（Docker Desktop 默认把 WSL 与 Windows 的 `localhost` 别名都解析到 Windows 宿主的 127.0.0.1）。因此**WSL 与 Windows 同时跑 Gateway 会抢端口**。日常开发建议：

- **Windows 优先**（性能更高，NTFS 原生，跨 9P 延迟消失）→ 启动 Windows 侧前后端
- 停 WSL 侧 Gateway / Vite（`kill` 对应 PID）
- 反向往返：先停 Windows 再启 WSL

| 端 | 进程 | 验证 |
|---|---|---|
| Windows Gateway | `java -jar gateway/target/...jar --spring.profiles.active=enterprise` | `curl http://localhost:8080/actuator/health → 200` |
| Windows 前端 | `npm run dev` (Vite :3000) | `curl http://localhost:3000/ → 200`, 标题「企业认知操作系统 \| C2EOS」 |
| WSL Gateway | 同 JAR，`/home/guorongxiao/.local/jdk/...` 启动 | `curl http://localhost:8080/actuator/health → 200` |

## §背景

来源：`docs/9-checks/2026-09-05-前端界面操作实现情况检查报告.md` §2.1 + §6（协调请求 1/2）。

本批次覆盖：
- **ai-engine 兼容路径**（对应 §2.1 #22/#23）：前端 `fetchAgentMetrics`/`fetchAgentErrors` 用 `/api/v1/agent-metrics/{agentId}` 但后端在 `/api/v1/aip/agent-metrics/{agentId}` — **合规做法**：在 ai-engine 新增薄 Controller `AgentMetricsCompatController`，委托给已存在的 `AipAgentMetricsService`（不新增业务逻辑，路径兼容层），保留 `/aip/agent-metrics` 主路径
- **data-workbench strategy/{id}**（对应 §2.1 #26）：`PUT /api/v1/datanet/metadata/strategy/{id}` + 同路径 PUT 别名 `/api/v1/datanet/metadata/strategy/{id}`，落到 `td_datasource.metadata_config` JSONB（PATCH 操作，单字段）
- **data-engine query template 单复数确认**（对应 §2.1 #24/#25）：后端 `/templates` 复数路径已有（`QueryController`），**本批不改**；任务要求 PM 指令确认 + 前端改前端路径到复数（PMO-44 T6 已覆盖）— 此处只列任务确认，未改代码
- **ontology sources 端点**（对应 §2.1 #18）：新增 `GET /api/v1/ecos/ontology/sources`，数据源为本体对象的 `sourceDomain/sourceManifest` 字段聚合
- **ontology preview 端点**（对应 §2.1 #17）：新增 `POST /api/v1/ecos/domains/{domainCode}/auto-discover/preview`，仅预览 entities 到内存，不写 DB（与现有 `POST /auto-discover` 的非 preview 版本严格区分）

## §禁止清单（铁律继承 + 本指令特有）

1. ❌ 不删除/重命名已有 `/api/v1/aip/agent-metrics` 主路径（API 只增不改，§0.2）
2. ❌ 不动 `td_datasource.metadata_config` 字段定义（PMO-37 已建）
3. ❌ 数据源 PUT strategy 不允许修改 `datasource_name/connector_type` 等独立字段（仅 strategy 字段）
4. ❌ ontology preview 不得写 DB（仅内存预览 + 返回）
5. ❌ 不新增 Maven 模块、不新增 Docker 容器
6. ❌ 适配 Controller 必须 `@ModelAttribute` 用 `@Qualifier` 注入已存在 Service，不 implements 已有接口

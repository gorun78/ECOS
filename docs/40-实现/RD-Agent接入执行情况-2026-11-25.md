**偏离 1（架构）**：报告要求审批「走现有 WAgent Candidate 咽喉」，实际实现是独立的
`ecos_scenario_run_approval` 表 + 自有语义。代码注释引用了 §5.5「候选唯一通道」，
但**实际未接入那条通道**。

首版只做逐字段对比；2026-11-25 补 `tree` 段（relation / commonAncestor / 两侧深度），
以父链回溯判定，不靠 `loop_index` 猜。

### §5.3 前端 — 四项达成 ✅

研究模式面板（默认折叠、不扰动原路径）、谱系树缩进 + SOTA 高亮、审批入口 + 凭据输入、
不新增顶级路由（复用 `#/workbench/:scenarioId`）。

### §5.4 沙盒七项约束 — 部分落地（2026-11-25 补建容器）

**2026-11-25 用户裁决「要」建沙盒容器**，容器基线 9 → **10**。已建成
`ecos-docker/research-sandbox`（声明式算子沙盒，零代码执行），隔离九项全部实测通过。

| 报告要求 | 实际 |
|---|---|
| 独立容器、非 root、只读根文件系统 | ✅ 非 root(10001) + 只读根 + tmpfs（实测 `touch` 报 Read-only） |
| 出口白名单、禁连生产库 | ⚠️ 未做白名单；实测**完全无出网**（DNS 黑洞，容器内 curl 返回 000） |
| CPU/内存/时长配额、超时强杀 | ⚠️ CPU/内存/PID 已限（0.5/192m/48）；**无超时强杀** |
| 只读快照 + 租户标记 + sha256 | ⚠️ 有 sha256 摘要；快照仅 3 列，**无租户标记** |
| 研究专用短期令牌 | ❌ 仅中继调用方凭证头 |
| 产物落 MinIO、DB 存引用 | ❌ 表已建，无写入路径 |
| 全链路审计留痕 | ❌ 沙盒只写 stderr，未接审计表 |

**能力边界（关键）**：沙盒是**声明式算子**（count/sum/avg/min/max/distinct_count），
**不是**任意代码执行环境。RD-Agent 的 `Coder`（CoSTEER）能力**仍未接入**——
这是有意的安全取舍，不是遗漏。详见
`docs/40-实现/L3研究沙盒部署与隔离验证-2026-11-25.md`。

### §4 执行序列 — implement 与 sandbox_run 缺失 ❌

报告五步 `hypothesize → implement → sandbox_run → evaluate → record`：
已实现 **hypothesize / evaluate / record** 三步；`implement`（沙盒内生成代码）与
`sandbox_run`（真隔离执行）**完全没有**。只读执行器仅做「查绑定 / 查知识命中 / 聚合读数」。

**这意味着 RD-Agent 的核心能力（代码进化）未接入**，当前是只读研究循环。

## 三、结论与后续前置

已完成的部分经审、经测、经活体验证，可作为 Phase 1 的接入底座。
**沙盒容器已建并实测隔离**（九项全过），后端到沙盒的端到端链路已打通
（`stop=ACCEPTED`，`exec_trace` 落库 274 字符，修复了原先落 null 的缺陷）。

但**报告的最终目标——沙盒内的代码进化循环（RD-Agent `Coder`/CoSTEER）——尚未实现**。
当前沙盒是**声明式算子**，只做确定性聚合，不执行生成代码。这是对报告 R2「极高风险」
的有意取舍，需要用户明确是否要跨到「真代码执行」这一步。

剩余缺口（按优先级）：

1. **Coder 能力**：若要 RD-Agent 式代码进化，须在沙盒内引入受控解释器 + 资源沙箱，
   风险等级会从「低」回到「极高」，需单独安全评审。
2. **业务数据**：`ecos_dw` 业务域实测仅 2 行，L3 目前无真实业务切片可研究。
   这是数据侧前置，不是代码问题。
3. **审计与令牌**：沙盒未接 ECOS 审计表，也无短期令牌（报告 §5.4 未闭环）。
4. **产物落 MinIO**：表已建，无写入路径。

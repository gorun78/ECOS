## 5. 追踪方式

1. **看板**：`hermes kanban --board swarm`（board 从 `~/ECOS/.hermes/agents.json` 读，禁止 default 回退）
2. **派发**：PM 按 PMO 指令 → `hermes kanban swarm --worker <fullstack-*> --verifier <reviewer-*> --synthesizer <pm-*>`，worker 标题禁冒号（**worker-title-colon-trap**）
3. **追踪**：`hermes kanban --board <board> list --json` 一次性获取全量数据。**禁止逐条 show**（O(n) 网络陷阱）
4. **每波完成后**：`git diff --stat` 检查产出落回项目目录；swarm 在 scratch workspace 隔离
5. **Repository 状态**：写入 `~/.hermes/features/features_v4.json`（按 PMO-38-47 编号 group）

### P0-2: Function 沙箱执行引擎（2天）

**目标**: 后端实现受限表达式计算引擎，编译→执行→缓存→审计。

**设计原则**:
- 不是通用脚本引擎，是受限SQL聚合表达式计算器
- 白名单函数（SUM/AVG/COUNT/MIN/MAX/+/-/*/ /CASE WHEN）
- 执行模型: 表达式编译→JdbcTemplate参数化查询→单值返回
- 超时5s，Caffeine缓存TTL 300s
- 每次调用写审计日志

**后端文件**:

| 文件 | 操作 | 说明 |
|------|------|------|
| `engine/ontology-engine/ontology-engine-impl/.../engine/FunctionSandboxEngine.java` | **新建** | 核心引擎：解析→验证→编译→执行 |
| `engine/ontology-engine/ontology-engine-impl/.../engine/FunctionValidator.java` | **新建** | 表达式白名单验证、DAG无环检查 |
| `engine/ontology-engine/ontology-engine-impl/.../engine/FunctionCacheManager.java` | **新建** | Caffeine缓存+本体变更时失效 |
| `engine/ontology-engine/ontology-engine-impl/.../controller/FunctionController.java` | **新建** | 测试端点+执行端点 |
| `gateway/src/main/resources/db/migration/V4.2__function_audit.sql` | 新建 | `ecos_function_audit_log` 表 |

**API端点**:
| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/v1/ontology/functions/test` | POST | 测试Function表达式（沙箱执行+返回结果） |
| `/api/v1/ontology/functions/{id}/execute` | POST | 正式执行（带审计） |
| `/api/v1/ontology/functions/{id}/deps` | GET | 查询Function依赖图 |

**验收**:
```bash
# 测试Function表达式
curl -X POST /api/v1/ontology/functions/test \
  -d '{"expression":"SUM(amount) / COUNT(*) FROM fin_revenue WHERE period='\''2026-07'\''","entity":"fin_revenue"}'
# 期望: 200 + {"result": 45230.5, "executionTimeMs": 45}

# 验证审计日志
curl -X GET /api/v1/ontology/functions/audit?page=1
# 期望: 200 + 列表含最近调用记录

# 验证安全（禁止的表达式应被拦截）
curl -X POST /api/v1/ontology/functions/test \
  -d '{"expression":"Runtime.getRuntime().exec(\"ls\")"}'
# 期望: 400 + error "forbidden function"
```

## 三、P2 延后项（→ Phase 5）

| 项目 | 理由 |
|------|------|
| 本体市场（行业模板） | 需要至少3个完整行业模板才能交付，目前数据不足 |
| 跨本体对齐 | 需要多个本体域就绪后才能做对齐 |
| 多版本分支模型 | 当前线性版本够用，分支模型是Phase 5产品化需求 |
| 本体变更传播 | 依赖 Phase 5 全链路联调时验证 |
| Function 表达式编辑器（Monaco） | P0-2沙箱引擎就绪后，Monaco嵌入是前端锦上添花 |
| P2档 i18n（OntologyExplorer等） | Mock数据页面，替换真实数据时一并做 |

# 术语辨析：W Agent ≠ Agent ≠ AI

> 来源: AI Agent | 日期: 2026-10-05 | 责任人: AI Agent
> 版本: v1.0
> 依据: 分册10 §二 F10-01（REQ-WAG-01）+ ADR-16 + 需求检视报告 §十四.1
> 【2026-10-05 校订 v1.0】首次落地"W Agent ≠ Agent"术语辨析（分册10 M0 交付，随 25 端点 + 9 Controller + 14 张 V227~V240 DDL 走查 + 前端单通道护栏一并交付）。

---

## 一、三个术语的字面与判定

| 术语 | 语义 | 在 ECOS 的落位 | 代码/DDL 载体 |
|:--|:--|:--|:--|
| **W Agent**（W·火·编排） | 五引擎 `D/I/K/C/W` 中的 **W 域**："谁**编排** D/I/K/C、按什么规则编排、编排留痕落在哪"。**不是执行体**，是编排记录/候选/证据/决策/行动 的控制面集合 | `com.chinacreator.gzcm.ai.wagent.*`（ai-engine，aiming:18084）；`ecos_ai` schema 内的 **V227~V240** 14 张表（不建 `ecos_agent` schema，铁律 §292 + ADR-17） | 9 个 Controller（`wagent/web/`）；25 端点 `operationId`；前端单通道 `services/wagentApi.ts` |
| **Agent**（运行态） | 已有 `AgentLoopService` 等 runtime 语义的瞬时执行器：**think → act → observe → think** 循环，工具调用上限 5 轮 | `com.chinacreator.gzcm.engine.ai.service.AgentLoopService` 及 `AgentRuntime*` 系列（存量，只增不改） | `/api/v1/agent-loop/*`（先存在的路径，W Agent **不得**改写其签名） |
| **AI**（泛指） | 模型/提示词/token 计量等泛"智能体能力"的总称；不用于类名/包名/doc 主标题 | 概念级；具体能力按域下属 | 各自引擎自管（如 `cognitive-engine`） |

## 二、代码包与路径约定（不可互换）

1. **包名**：W Agent 编排域一律位于 `com.chinacreator.gzcm.ai.wagent.*`（`wagent/web/` 落 9 个 Controller，其余子包 `engine/orchestrator/readiness/tool/candidate/circuit/governance/guard/promptinjection/degrade/evidence/narrative/autos`）。**禁混用** `com.chinacreator.gzcm.engine.ai.*`（那是"Agent runtime"语义）。
2. **URL**：W Agent 端点一律 `/api/v1/wagent/*`（24 个路径 × 25 个 `operationId`，唯一 HEAD 路径 `draftAction`+`commitAction`）。**禁与** `/api/v1/agent*` `/api/v1/agent-loop/*` 混用（铁律 §435 Ant 匹配不互覆）。
3. **DDL**：V227~V240 单源目录 `gateway/src/main/resources/db/migration/`，`SCHEMA ESCO_AI`（ADR-17；ST07 五枚举内，禁第 12 个 schema）。**禁** `CREATE SCHEMA ecos_agent`。

## 三、典型反例（评审必查）

| 反例 | 修正 |
|:--|:--|
| 在 `com.chinacreator.gzcm.engine.ai.service.AgentLoopService` 里加 wagent 方法 | 迁到 `com.chinacreator.gzcm.ai.wagent.orchestrator.*`，允许但不必调 `AgentLoopService`（两者解耦） |
| 前端页面 `raw fetch("/api/v1/wagent/runs")` 跳过 `services/wagentApi.ts` | 违反 C181-style 单通道纪律（`wagentApi-single-channel.test.ts` 会 fail-loud） |
| DDL `CREATE TABLE ecos_agent.wagent_run(...)` | 改为 `ecto_ai.wagent_run`（V227~V240 已按此落位） |
| 把 W Agent 命名为 "WAgent execution" 并放到 agent-loop Controller 里做路由 | 语义混淆。W Agent 是**编排留痕**，不是执行器；执行器是 Agent/AgentLoop |

## 四、ADR-16 落地口径（本文件有效锚点）

- **判定原则**：一个类/表/端点如果新增属于"W 域控制面对象"（Run / Plan / Step / Tool / Candidate / Claim / Decision / Action / Evidence 之一），一律走 `com.chinacreator.gzcm.ai.wagent.*`；如果只是"跑一个 LLM 回路"，走存量 `AgentLoopService` 且**不改签名**。
- **本文件更新规则**：只在 ADR-16 结论变更、或发现新的术语混用时整段替换某节；不在既有行上做行内改动（R9 只增改）。

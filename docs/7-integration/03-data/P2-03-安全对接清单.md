# P2-03 安全对接清单

> ECOS data-engine | 2026-08-24 | 本轮确认对接点，逐项接线

## 一、原则

**data-engine 禁止自建权限/脱敏/审计**，全部调 security-engine + runtime-crypto。

## 三、凭据 crypto 对接

```java
// 数据源密码加密存储
@Service
public class DataSourceService {
    private final CryptoService cryptoService; // runtime-crypto
    
    public void createDataSource(DataSource ds) {
        ds.setPassword(cryptoService.encrypt(ds.getPassword()));
        jdbc.update("INSERT INTO ...", ...);
    }
    
    public DataSource getDataSource(String id) {
        DataSource ds = jdbc.queryForObject("SELECT ...", ...);
        ds.setPassword(cryptoService.decrypt(ds.getPassword()));
        return ds;
    }
}
```

## 四、访问控制对接

数据源/管道的访问走 security-engine 准入等级 + ABAC：

```java
// QueryController 执行前 ABAC 评估
@PostMapping("/execute")
public ApiResponse execute(@RequestBody QueryRequest req) {
    // ABAC evaluate
    boolean allowed = securityPolicyClient.evaluate(
        currentUserId(), "read", "datasource:" + req.getDatasourceId());
    if (!allowed) throw new ForbiddenException("无数据源访问权限");
    // 执行查询
    return ApiResponse.success(queryService.execute(req));
}
```

## 五、查询脱敏对接

```java
// QueryController 结果脱敏
@PostMapping("/execute")
public ApiResponse execute(@RequestBody QueryRequest req) {
    List<Map<String, Object>> rows = queryService.execute(req);
    // 调 security-engine 脱敏
    rows = maskingClient.mask(rows, Arrays.asList("email", "phone", "idCard"));
    return ApiResponse.success(rows);
}
```

## 六、操作审计对接

```java
// Pipeline 执行后写审计
public void triggerRun(String taskId) {
    // 执行 pipeline
    executionEngine.execute(runId);
    // 写审计
    auditClient.log(AuditEvent.builder()
        .userId(currentUserId())
        .action("PIPELINE_RUN")
        .resource("pipeline:" + taskId)
        .result("SUCCESS")
        .build());
}
```

## 七、禁止事项

- ❌ data-engine 自建权限系统
- ❌ data-engine 自建脱敏逻辑
- ❌ data-engine 自建审计表
- ❌ 明码密码入库

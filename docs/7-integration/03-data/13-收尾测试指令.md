### T3 — Pipeline 端到端执行验证（杀手锏）

**操作**：
1. 确认 td_datasource 有至少 1 个 PostgreSQL 数据源（若空则建一个测试数据源）
2. 创建 Pipeline 定义（2 节点：SOURCE_JDBC → OUTPUT_OBJECT）：
   ```json
   {
     "name": "测试Pipeline-请删除",
     "nodes": [
       {"id": "src1", "type": "SOURCE_JDBC", "config": {"datasourceId": "<真实ID>", "sql": "SELECT 1 as test_col"}},
       {"id": "out1", "type": "OUTPUT_OBJECT", "config": {"targetTable": "ecos_test_pipeline_output", "mode": "overwrite"}}
     ],
     "edges": [{"source": "src1", "target": "out1"}]
   }
   ```
3. 执行 Pipeline：`POST /api/v1/pipeline/definitions/{id}/execute`
4. 查执行状态：`GET /api/v1/pipeline/executions/{taskId}` 或轮询 `taskManagementService.getTaskStatus(taskId)`
5. 查 `ecos_pipeline_execution` 表：`SELECT status, rows_processed, error_message FROM ecos_pipeline_execution WHERE id = ?`
6. 清理测试数据

**验收**：
- 执行返回 taskId（走 runtime-task，不是裸 executionId）
- ecos_pipeline_execution 状态 = COMPLETED（或 FAILED + 有明确 error_message）
- SOURCE_JDBC 节点走 ConnectorFactory（日志可见 `Connector type: JDBC`，不是系统 JdbcTemplate）
- ITaskStatusCallback 回调链完整（日志可见 onStepStart/onStepComplete/onProgressUpdate/onTaskComplete）
- 测试数据清理干净

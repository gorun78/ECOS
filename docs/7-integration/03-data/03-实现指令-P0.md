data-engine 后端核心能力已真实落地（血缘/DQ/Schema检测/Pipeline异步），但摸底实测发现 4 个纯 bug（B1/B2/B3/B4）：功能"看似有、实际 404 或空转"。本轮修复，每个独立 commit。

## §禁止清单（继承架构规则 5.1 + 本指令特有）

1. 不跨 Phase 预创建文件
2. 新增端点不过三滤波器（VersionPrefixRewriteFilter / SecurityConfig / ClearanceInterceptor）
3. 改前端路径迁就后端
4. T1 禁止保留自建 ExecutorService（违反架构规则 2.3「定时任务不自建 ScheduledExecutorService」）
5. 动 kb-engine / cognitive-engine（Phase 5/6）

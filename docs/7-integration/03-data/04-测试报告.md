### T3 发现的 bug: api.ts 缺 Authorization header

| 项 | 值 |
|----|-----|
| 严重度 | P1 |
| 根因 | data-workbench/api.ts 的 get()/post()/createPipeline等函数直接用 fetch() 不带 Authorization header，导致需认证的端点 (/api/integration/metadata, /api/v1/pipeline/definitions) 返回 403，前端 syncs/pipelines Tab 无法加载数据 |
| 修复 | 新增 authHeaders() 从 localStorage 读取 token，所有 fetch 调用统一注入 Authorization: Bearer {token} |
| Commit | `09ec08a` |
| 复验 | 前端 /api/integration/metadata 200 (之前 403)，syncs Tab 显示 4 个真实任务 ✅ |

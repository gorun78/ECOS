## §背景

前端数据工作台摸底发现 4 类不完善：① 4 个 Prototype mock 假页面 ② connections/syncs Tab 对接内存 mock（PMO-3E 已真实化后端）③ ~3200 行硬编码中文 ④ 大文件偏多。

按合理性可大改——假功能直接删，不留面子。

## §专家意见（为什么这么改）

1. **4 个 Prototype 是 ceos_new 原型残留**：ECOS 是企业经营管控平台，没有"代码仓库/工作簿/Contour"这些功能，它们是演示假页面。**删除**比"对接假后端"更诚实。pipeline-builder 有真实功能（PipelineFlowEditor 305 行），对接它。
2. **connections/syncs 必须对接真实数据**：内存 mock 的 doris/postgresql 假连接会误导用户以为有数据接入，实际 td_datasource 是空的。PMO-3E 已把后端真实化，前端 API 层要跟上。
3. **i18n 是架构规则 4.3 强制**，不是可选。

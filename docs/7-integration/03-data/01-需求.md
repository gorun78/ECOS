## 8. 风险 / 局限

| 风险 | 等级 | 缓解 |
|:--|:--:|:--|
| transform 模块原注释 `// TODO D4: 归位 ge-service（格）` 提示后续可能独立抽包 | 中 | 本次保持 impl 内 (铁律 §5.1 #10 不新增 Maven 模块)，未来若独立拆分需走 A1-x 迁移 PMO 流程 |
| 6 个 TransformStep 无 `@Component` 注解 (历史代码) | 低 | Controller 内按 type 字符串 `new` 实例化；如未来 Bean 化需加 `@Component(name="typeCleansing")` 并在 Controller 改用 `getBean("type"+Type)` |
| CalculatorStep 用 Nashorn (JS 脚本引擎) | 中 | Java 17 默认无 Nashorn，`CalculatorStep.transform` 在 JDK17 上若执行 JS 表达式返回 null 引擎 → 风险在脚本引擎不可用时才暴露，且非本次 T4 范围；若需实施可另开 PMO-Ge4-nashorn-fallback |

### 补做要求（3 项，前后端协同，每项附 curl 验收）

#### 1.1 绑定物理工作站登录校验

- **后端**：`sysman-boot/AuthController` 登录成功后校验客户端 IP/MAC vs `linked_workstation`，不匹配 → 拒绝 + 审计 `workstation_mismatch`
- **前端**：`UserEditModal`/`SecurityConfigPanel` 编辑工作站绑定，自动获取展示当前客户端 IP/MAC
- **验收**：用户绑定工作站 A（如 `10.0.0.1`），从工作站 B 登录 → 拒绝 + 审计记录 workstation_mismatch

#### 1.2 双写审计力度分级

- **后端**：`sysman-impl/AuditAspect` 按 `audit_mode` 分级——basic 只记关键操作（登录/删除/权限变更）、detailed +请求参数、full 联动 `AuditHashChainService` 哈希链双写
- **前端**：`SecurityConfigPanel` 编辑力度 + 展示哈希链验证状态
- **验收**：full 模式用户执行操作 → DB 有记录 + 哈希链有对应 hash；basic 模式 → 只 DB 记录关键操作

#### 1.3 高危指令沙盒审查

- **后端**：`ai-engine/ToolExecutorService` 检查 `sandbox_mandatory`，高危指令（DELETE/DROP/批量UPDATE/系统命令/DDL/越权SQL）先调 `SecuritySandboxService` 审查，高风险 → 拒绝 + 审计
- **前端**：`SecurityConfigPanel` 开关 + `AgentTestConsole` 展示审查拦截记录
- **验收**：sandbox_mandatory=true 用户 Agent 执行 DELETE → 沙盒拦截 + 审计，不放行

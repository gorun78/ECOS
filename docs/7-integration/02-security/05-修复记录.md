## 缺陷 1：审计写入端点缺失

| 项 | 值 |
|----|-----|
| 严重度 | P0 |
| 根因 | AuditController 仅有 GET /logs + GET /stats，缺少 POST 写入端点。前端 SecurityAudit 组件的审计日志只能查不能写，各引擎无法通过 API 写审计日志。 |
| 修复 | AuditController.java 新增 `POST /log` 端点，接收 {userId, action, resource, result, detail}，异步调用 `auditLogService.log()` 写入 ecos_audit_log 表，不阻塞调用方。返回 `ApiResponse.success(Map.of("status", "accepted"))`。 |
| Commit | (BE subagent commit) |
| 复验 | curl POST /api/v1/security/audit/log → code=0, data={status:"accepted"}, 响应 60ms（异步）。GET /api/v1/audit/logs 可查到写入的记录。✅ |

> 来源: 肖国荣 | 日期: 2026-08-25 | 需求蓝本: docs/4-onto/01-差距分析.md §7.8
> 模块定位: DIKW 中 I（信息）层 —— 本体是数据（D）与知识（K）之间的语义桥梁。不是画 ER 图的工具，是让企业数据"可理解、可推理、可治理"的语义基础设施。

## 八、架构规则约束（铁律）

1. 架构规则 2.5：基础设施访问收敛 runtime-access（图查询走 PgGraphService/Neo4jGraphService，不直接 JdbcTemplate）
2. 架构规则 4.1：禁硬编码 Tailwind 颜色 → useTheme()
3. 架构规则 4.3：i18n，禁硬编码中文
4. **Flyway 已禁用**：新增表必须 @PostConstruct CREATE TABLE IF NOT EXISTS 兜底，不能只写迁移文件（data-engine 的 PipelineRepository 教训）
5. 架构规则 5.4：Function 沙箱零外部依赖（手写解析器，禁 Aviator/MVEL/SpEL）

### 缺陷 #2c: Console 401/404 + GoalTreeNode key prop 警告

| 项 | 内容 |
|---|---|
| 编号 | I1-pre-02c |
| 严重度 | 低 |
| 现象 | Playwright 收集到 4 条 console error: 401 Unauthorized (API 未携带 token)、404 Not Found、GoalTreeNode `key` prop 警告 |

| 状态 | 记录，低优先级 |

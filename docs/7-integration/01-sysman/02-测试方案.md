## §6 风险等级与阻断决策

| 风险 | 等级 | 触发条件 | 动作 |
|:--|:--|:--|:--|
| Bean 拼接失败 (current) | **P0 Blocker** | `gateway` mvn install 后 `mvn spring-boot:run` 报 `UnsatisfiedDependencyException: CognitiveService ctor → cognitive.impl.RuleEngine` | 阻断 Wave-1A 现场跑测; 上报 Fullstack 修复 ai-engine-impl.CognitiveService 跨模块依赖 (违反铁律 §2.1 「引擎间只调 API」) |
| Gateway 不可达 (timeout 5s) | **P1** | `GET /api/health` 非 200 | 所有 50 套输出 `ENV_BLOCKED` exit 77, Wave-1A 不阻塞, 但 deliverable_allowed=false |
| 某 P1 用例收到 `2XX` 越权 | **P0** | 任一 T1/T2/T4 返回 2XX 给无 token | 立即阻断 (同 TC_BLOCKED 规则) |
| PG 不可用 | P2 | docker 未起 | 限制在 T5 契约类 (无需 DB), 标记 §1.3 不变的 30 套 |
| 时间不允许 (deadline - 2h) | P2 | — | Wave-1A 仅做 T1+T5 (20 套) PASS 率, 其余 P2 入 §1.3 |

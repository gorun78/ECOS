## §1 test_* 入口与出口

```js
// 统一入口 (lib/security.mjs)
export const BASE        // http://localhost:8080 (可被 ECOS_BASE 覆盖)
export const ADMIN       // { username, password }
export async function login(username?, password?)         // 失败抛 LOGIN_FAILED
export async function gatewayAlive()                       // 探活: GET /api/health → boolean
export async function req(method, path, {token, body}?)   // 通用请求包装, 返回 {status, body, headers}
export function expectForbid(st, msg)   // 401 || 403 (默认 DENY)
export function expectAllow(st, msg)    // 2XX
export function expect404(st, msg)
export function expectStatus(exp, st, msg)
export function expectJsonField(obj, field, msg)
export function report(label)           // exit 0
export function reportFail(label, e)    // exit 1
```

**测试用例模板** (50 套均为该结构):

```js
import { req, gatewayAlive, reportFail, report } from "../../lib/security.mjs";

try {
  if (!(await gatewayAlive())) {
    process.exit(77); // ENV_BLOCKED
  }
  const r = await req("GET", "<path>", {});
  if (r.status >= 200 && r.status < 400 && r.status !== 404) {
    throw new Error("默认 DENY 突破: " + r.status);
  }
  report("T*-0** (status=" + r.status + ")");
} catch (e) {
  reportFail("T*-0**", e);
}
```

### 1.1 退出码语义

| code | 含义 |
|:--|:--|
| `0` | **PASS** (默认 DENY 拦截) / 忽略 PRD-超前接口 404 |
| `1` | **FAIL** (越权拦截被突破, 收到 2XX / 异常) |
| `77` | **ENV_BLOCKED** (Gateway 不可达 / 依赖不可用, 不计入 PASS/FAIL) |
| `2` | **环境/参数错误** (脚本自身语法 / import 失败) |

**Wave-1A 合 tag 决策**: `PASS=x, FAIL=y, ENV_BLOCKED=z` → **z ≤ 5 且 x ≥ 40 且 y = 0** 时合 tag, 否则禁止合入。

## §6 风险 / 块 (P0 Blocker) ⛔

```
2026-09-01 19:13:26  [main]   o.s.b.d.LoggingFailureAnalysisReporter:
Parameter 0 of constructor in com.chinacreator.gzcm.engine.ai.service.CognitiveService
required a bean of type 'com.chinacreator.gzcm.cognitive.impl.RuleEngine' that could not be found.

考虑 defining a bean of type 'cognitive.impl.RuleEngine' in your configuration.
```

**根因**: `ai-engine-impl/CognitiveService.java` 构造器注入 `cognitive.impl.RuleEngine` (impl 类, 不是 api interface), 违反 架构铁律 §2.1 — 引擎间只调 API 不调 Impl。**需要 Fullstack 在 cognitive-engine-api 新增 `IRuleEngine` 接口 (mvn install 后重新 install cognitive-engine-api 让 ai-engine-impl 引用 interface)。**

参考实现路径:

```java
// engine/cognitive-engine/cognitive-engine-api/.../api/IRuleEngine.java (新增)
public interface IRuleEngine {
    List<MatchedRule> evaluate(Map<String, Object> facts);
}

// engine/cognitive-engine/cognitive-engine-impl/.../impl/RuleEngine.java
// @Component 已存在 (verify) | implements IRuleEngine (新增)

// engine/ai-engine/ai-engine-impl/.../service/CognitiveService.java
- private final RuleEngine ruleEngine;     // ✗ impl
+ private final IRuleEngine ruleEngine;    // ✓ api interface
- public CognitiveService(RuleEngine ruleEngine, ...) {
+ public CognitiveService(IRuleEngine ruleEngine, ...) {
```

> 此为 PMO 模型映射, 不可在 QA 阶段修改 Java 文件 (约束 #4 与 Agent 默认重复)

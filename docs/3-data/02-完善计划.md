## 四、风险

| 风险 | 概率 | 缓解 |
|------|:--:|------|
| cognitive-engine因果链≥3层需要大量Neo4j数据，当前图谱为空 | 高 | Phase 3c联调时先导入科创财务数据建图，POC数据先行 |
| JSqlParser对达梦/金仓等国产DB的SQL方言兼容性 | 中 | 先支持PG/MySQL标准SQL，国产DB降级为正则 |
| 知识抽取PDF解析质量依赖MinerU | 中 | 支持手动标注作为fallback |
| i18n 1800行硬编码迁移工作量被低估 | 中 | 先跑自动化脚本批量替换常见模式，再人工审核 |
| 前端6大文件拆分后路由/Tab切换逻辑断裂 | 中 | 每次拆分后npm run dev验证，不攒到最后 |
